## 📱 全平台客户端推荐与分流配置

### 1. 常用客户端选型

| 平台 | 推荐客户端 | 核心优势 |
| :--- | :--- | :--- |
| **Windows** | Clash Verge Rev / Flclash | 内置 Mihomo/Meta 内核，界面现代，支持一键分流与订阅管理 |
| **macOS** | Clash Verge Rev / Surge (商业授权) | 深度适配 Apple Silicon，内存占用低，支持增强模式 |
| **Android** | Clash Meta for Android / v2rayNG | 支持分应用代理（绕过国内银行/微信应用），稳定性高 |

### 2. 基础分流策略建议
* **规则分流 (Rule)**：推荐日常保持开启，国内直连、国外走代理，节省流量且不影响国内 App 速度。
* **全局模式 (Global)**：仅在特定海外服务（如部分小众 AI 站点）因规则未覆盖导致无法访问时临时使用。
* **TUN / 增强模式**：游戏加速、命令行终端 (Git/npm) 或无代理设置的桌面应用需代理时开启。

## 🛠️ 节点排错与网络优化速查

* **节点全部超时 (Timeout)**：
  1. 检查客户端本地系统时间是否与网络时间同步（误差超 60 秒会导致加密握手失败）。
  2. 尝试将节点模式切换为「直接连接」后再更新一次订阅 URL。
* **AI 提示 Access Denied / 403 封锁**：
  * 切换至非机房 IP 节点（选择标注有「原生/Residential」的美国或新加坡节点）。
  * 清除浏览器 Cookie 或开启无痕模式重新打开。
* **YouTube 默认画质低**：
  * 在客户端中测速，选择延迟低且非拥堵的节点（避免选择 0.1x 等高倍率限速节点）。

<a id="常见问题-faq" name="常见问题-faq"></a>
## ❓ 常见问题 (FAQ)

<details>
<summary><b>Q1: IPLC / IEPL 专线与普通公网中转、直连线路有什么区别？</b></summary>

* **IPLC / IEPL（国际私有专线）**：流量通过海底光缆或陆地物理内网直接过境，完全不经过公网防火墙（GFW），具有**零丢包、低延迟、抗封锁**的特点。
* **普通公网中转**：国内服务器接收入口流量后加密走公网出口，成本较低，但晚高峰或敏感时期可能偶发波动。
* **直连线路**：客户端直接连接海外服务器，极易被干扰限速。
</details>

<details>
<summary><b>Q2: 为什么有的机场节点倍率是 0.1x，有的是 2x / 5x？</b></summary>

节点倍率代表消耗流量的计算权重：
* **1.0x（基准倍率）**：使用 1GB 流量扣除 1GB 额度。
* **0.1x ~ 0.5x（低倍率节点）**：通常用于下载大文件或缓存视频，扣除流量打折。
* **2.0x ~ 10x（高倍率节点）**：通常部署在昂贵的高清原生 IP 节点、高防服务器或超低延迟游戏专线。
</details>

<details>
<summary><b>Q3: 遇到特殊时期节点频繁断连怎么办？</b></summary>

1. **更新订阅**：登录机场官网，重新拉取最新订阅链接并全量更新节点。
2. **切换协议**：优先选用 VLESS、Hysteria2、TUIC 或 Trojan 等抗封锁能力较强的新一代协议。
3. **备用策略**：主力使用旗舰 IEPL 专线，同时搭配一个平价不限时流量包作为备用容灾方案。
</details>

<details>
<summary><b>Q4: 客户端导入订阅失败或提示「网络错误」？</b></summary>

1. **节点官网域名变更**：部分机场会定期更换订阅下发域名，请登录官网重新复制最新的一键导入链接。
2. **本地代理冲突**：更新订阅前，先关闭客户端的「系统代理」开关，使用本地直连网络尝试更新。
3. **系统时间不准确**：检查电脑/手机本地系统时间，与网络标准时间误差超过 60 秒会导致 SSL 证书握手失败。
4. **客户端版本过旧**：更新至最新版客户端（如 Clash Verge Rev 最新版），以支持最新的协议与配置格式。
</details>

<details>
<summary><b>Q5: 观看 Netflix / Disney+ 提示使用代理被拦截或只能看自制剧？</b></summary>

流媒体平台会定期屏蔽已被识别的机房出口 IP。
* 切换至机场专门标注为「NF / 流媒体解锁」的专用节点。
* 确认客户端分流规则中已包含该平台的规则集（Rule-Set），避免分流走到了不具备解锁能力的备用落地节点。
</details>

<details>
<summary><b>Q6: 应该买「按月付费」还是「按年付费」？</b></summary>

* **新手首选月付 / 季付**：首次使用某家服务商时，建议先购买月付套餐，在本地宽带和晚高峰时段实测 1~2 周，体验满意且稳定后再考虑长周期。
* **高性价比年付**：如需享受最大折扣（如可信云/瞬云的长周期特惠），建议选择运营时间长、口碑良好的老牌专线服务商。
* **常备不限时流量**：建议始终搭配一个按量计费/不限时套餐作为备用，防止主力节点突发故障时失联。
</details>

<details>
<summary><b>Q7: 什么是 TUN 模式 / 虚拟网卡模式？什么时候需要开启？</b></summary>

常规代理模式仅对支持 HTTP/SOCKS5 代理协议的软件（如浏览器）生效。
* **开启 TUN 模式**后，客户端会在系统内创建虚拟网卡，接管所有网络流量。
* **适用场景**：Steam / Epic 联机游戏加速、Git 终端命令行拉取代码、未配置独立代理的桌面应用程序、模拟器等。
</details>

<details>
<summary><b>Q8: 原生住宅 IP（Residential IP）是什么？与普通机房 IP 相比有什么优势？</b></summary>

原生住宅 IP 是由当地民用宽带运营商（如 AT&T、Comcast 等）分配的家庭宽带 IP，而非数据中心云服务器 IP。
* **核心优势**：风控等级极低，能够完美避开海外金融银行、TikTok 运营、跨境电商平台（Amazon/eBay）及高端流媒体的机房风控检测。
</details>
