## 🛠️ 节点排错与网络优化速查

* **节点全部超时 (Timeout)**：
  1. 检查客户端本地系统时间是否与网络时间同步（误差超 60 秒会导致加密握手失败）。
  2. 尝试将节点模式切换为「直接连接」后再更新一次订阅 URL。
* **AI 提示 Access Denied / 403 封锁**：
  * 切换至非机房 IP 节点（选择标注有「原生/Residential」的美国或新加坡节点）。
  * 清除浏览器 Cookie 或开启无痕模式重新打开。
* **YouTube 默认画质低**：
  * 在客户端中测速，选择延迟低且非拥堵的节点（避免选择 0.1x 等高倍率限速节点）。

## ❓ 常见问题 (FAQ)

<details>
<summary><b>Q1: 为什么访问 ChatGPT / Claude / Gemini 提示「Access Denied」或地区不受支持？</b></summary>

主流 AI 平台对数据中心机房 IP（如常见的数据中心 VPS）有极其严格的风控机制。
* **解决方案**：
  1. 在客户端节点列表中选择标注有「原生 / 解锁 / Residential / 家宽」的美国、新加坡或日本节点（如推荐清单中的**云图**原生IP节点）。
  2. 开启客户端的 **TUN 模式** 或临时切换为 **全局模式 (Global)**，避免规则未覆盖导致部分 WebSockets/验证接口走直连。
  3. 清理浏览器 Cookie 与 Local Storage，或开启浏览器无痕/隐私窗口重新登录。
</details>

<details>
<summary><b>Q2: IPLC / IEPL 专线、中转节点和直连节点有什么区别？该怎么选？</b></summary>

* **IPLC / IEPL 专线**（如极连云、速界、可信云）：物理内网光纤点对点连接，流量不经过公网 GFW，晚高峰零丢包、低延迟、抗封锁能力最强，适合商务、游戏与主力看剧。
* **BGP / 优质中转**（如光年梯、快狸）：国内服务器接收入口流量，再通过公网隧道加密转发至海外落地机，性价比较高，晚高峰受骨干网波动影响略大于专线。
* **普通直连**：设备直接连接海外服务器，极易被识别干扰，延迟高、易断连，仅适合超低成本轻度备用。
</details>

<details>
<summary><b>Q3: 什么是「节点倍率」？为什么有的节点消耗流量特别快？</b></summary>

倍率是机场统计流量时的乘数：
* **1.0x（标准倍率）**：使用 1GB 流量，账户后台扣除 1GB 流量。推荐清单中的**极连云、云图**全节点承诺 1 倍率无陷阱。
* **高倍率（如 2.0x ~ 5.0x）**：通常出现在高成本专线或稀缺家宽节点上，消耗 1GB 会扣除 2~5GB 流量。
* **低倍率（如 0.1x ~ 0.5x）**：通常为大流量下载节点，适合下载大文件，但晚高峰速度与稳定性相对一般。
</details>

<details>
<summary><b>Q4: 为什么订阅链接在 Clash / Shadowrocket 中无法更新或报错？</b></summary>

1. **节点官网域名变更**：部分机场会定期更换订阅下发域名，请登录官网重新复制最新的一键导入链接。
2. **本地代理冲突**：更新订阅前，先关闭客户端的「系统代理」开关，使用本地直连网络尝试更新。
3. **系统时间不准确**：检查电脑/手机本地系统时间，与网络标准时间误差超过 60 秒会导致 SSL 证书握手失败。
4. **客户端版本过旧**：更新至最新版客户端（如 Clash Verge Rev 最新版），以支持最新的协议与配置格式。
</details>

<details>
<summary><b>Q5: 观看 Netflix / Disney+ 提示使用代理被拦截或只能看自制剧？</b></summary>

流媒体平台会定期屏蔽已被识别的机房出口 IP。
* 切换至机场专门标注为「NF / 流媒体解锁」的专用节点。
* 确认客户端分流规则中已包含该平台的规则集（Rule-Set），避免分流走到了不具备解锁能力的备用落地节点。
</details>

<details>
<summary><b>Q6: 应该买「按月付费」还是「按年付费」？</b></summary>

* **新手首选月付 / 季付**：首次使用某家服务商时，建议先购买月付套餐，在本地宽带和晚高峰时段实测 1~2 周，体验满意且稳定后再考虑长周期。
* **高性价比年付**：如需享受最大折扣（如可信云/瞬云的长周期特惠），建议选择运营时间长、口碑良好的老牌专线服务商。
* **常备不限时流量**：建议始终搭配一个按量计费/不限时套餐作为备用，防止主力节点突发故障时失联。
</details>

<details>
<summary><b>Q7: 什么是 TUN 模式 / 虚拟网卡模式？什么时候需要开启？</b></summary>

常规代理模式仅对支持 HTTP/SOCKS5 代理协议的软件（如浏览器）生效。
* **开启 TUN 模式**后，客户端会在系统内创建虚拟网卡，接管所有网络流量。
* **适用场景**：Steam / Epic 联机游戏加速、Git 终端命令行拉取代码、未配置独立代理的桌面应用程序、模拟器等。
</details>

<details>
<summary><b>Q8: 原生住宅 IP（Residential IP）是什么？与普通机房 IP 相比有什么优势？</b></summary>
